Website project · Christchurch

Kiwi Gardeners: a useful local website built around real gardening enquiries.

I helped develop KiwiGardeners.com so Christchurch residents can find practical garden advice, browse relevant local information and contact an independent gardener without unnecessary complexity.

The brief

The project connects useful Christchurch gardening information with a straightforward service enquiry path. Dallas Timpson is the independent gardener responsible for gardening work and quotes. My role has been website development and digital systems, not providing gardening services.

What I worked on

The website organises information into gardening services, Christchurch suburb pages and practical guides. We focused on readable page titles, navigation, responsive presentation, canonical URLs and an XML sitemap rather than producing pages solely to capture search traffic.

It is deployed using Cloudflare Workers with static assets. The contact form is a separate API path with Turnstile verification and rate limiting, and the API is marked not to be cached. Those safeguards support a straightforward enquiry experience without building a customer account or payment system.

What this example demonstrates

Small-business websites benefit when the design, local content and contact route reinforce one another. The result is a public website visitors can judge for themselves, not a claim of search rankings or unverified customer outcomes.
